## 🛠️ How to Compile (VS Code)
This project is built using LaTeX. To compile the PDF locally:

1.  **Prerequisites:**
    * [VS Code](https://code.visualstudio.com/)
    * [LaTeX Workshop Extension](https://marketplace.visualstudio.com/items?itemName=JamesYu.latex-workshop)
    * A TeX distribution (e.g., [TeX Live](https://tug.org/texlive/) for Linux/Windows or [MacTeX](https://tug.org/mactex/) for macOS).

2.  **Build Instructions:**
    * Open the `Thesis/` folder in VS Code.
    * Open `Thesis.tex`.
    * Press `Ctrl + Alt + B` (or open Command Palette and run `LaTeX Workshop: Build with recipe`).
    * The PDF will be generated in the same directory.
